9.Обрушение пола (Бездна)
Башня старая и рушится. Каждые 5 ходов внешний периметр пола карты превращается в Бездну (символ — пустота, в которую нельзя наступить). 
Карта постепенно сужается к центру. Если лестница вверх провалилась в бездну — нужно срочно эвакуироваться (Q).
